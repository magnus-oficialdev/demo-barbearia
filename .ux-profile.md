# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom — barbearia clássica, escura e marcante · Direção escolhida: **A — "Poste Aceso"** (ver `docs/direcoes.md`)
- **Notes:**
  - Referências: landing "Slick Style" (estrutura de seções, fotos fortes, preços em destaque) e logo "Braincut" (dourado sóbrio, vintage, "EST. 2022").
  - Fundo preto fosco / cinza carvão; amarelo âmbar como **único** acento (~10% da tela: CTAs, preços, destaques); texto em branco quente.
  - Títulos: **Big Shoulders Display** (condensada, de letreiro). Texto: **Barlow**. Sem rótulos em caixa alta acima dos títulos (eyebrows).
  - Elemento-assinatura: poste de barbeiro 3D procedural (three.js) no hero, listras amarelo/branco/preto, atravessando o nome da casa; parado com `prefers-reduced-motion`. É o único elemento ousado da página.
  - Fotos reais são as protagonistas (cortes, antes/depois, equipe, ambiente). Detalhes vintage (poste de barbeiro, "EST.") com moderação.
  - Superfícies separadas por bordas de 1px (`border`); sombras mínimas, nunca brilho.
  - Mobile-first: CTA "Agendar" sempre acessível (header fixo ou barra inferior no mobile).
  - Tokens de cor:

    | Token | Hex | Uso |

    | `bg` | `#161616` | fundo principal (preto fosco) |
    | `surface` | `#2B2B2B` | cards, seções |
    | `surface-2` | `#333333` | hover, inputs |
    | `border` | `#3D3D3D` | bordas 1px |
    | `accent` | `#F2B630` | CTA, destaques, preços |
    | `accent-hover` | `#FFC94A` | hover do CTA |

    | `text` | `#F2F2EE` | texto principal |
    | `text-muted` | `#9C9C9C` | texto secundário |

## Banned anti-aesthetics

- Glassmorphism / `backdrop-filter` sem borda de alto contraste
- Badges pastel flutuantes para metadados comuns
- Degradês decorativos arbitrários e bordas neon brilhando
- Degradês arco-íris / radiais multicoloridos em CTAs
- Ilustrações cartoon em estados vazios (pessoas acenando / high-five)
- Scroll aninhado e excesso de ícones dentro de inputs
- Cards tortos / inclinados / rotacionados
- Texturas (tijolo, grunge) atrás de texto
- Letras gigantes "fantasma" como fundo decorativo
- Qualquer cor de acento além do amarelo (`#F2B630`)

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 para texto normal; ≥ 3:1 para texto grande e bordas de UI. Calculado: `text` sobre `bg` 16,12:1; `text` sobre `surface` 12,62:1; `text-muted` sobre `bg` 6,59:1 e sobre `surface` 5,16:1; `on-accent` sobre `accent` 9,92:1.
- **Touch / focus:** alvos de toque ≥ 44×44px; anel de foco de 2px em `accent` com offset de 2px, sempre visível no teclado.

## Brand tone and microcopy voice

- **Voice:** Opinionated & Direct
- **Capitalization:** Sentence case for UI copy and buttons (caixa alta só como estilo visual de títulos/eyebrows via CSS `text-transform`)
- **Notes:** Português do Brasil. Frases curtas e firmes, verbo primeiro ("Agende seu corte", "Ver horários", "Escolher barbeiro"). Personalidade sem gíria forçada e sem jargão.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide` / `lucide-react` (conforme o stack escolhido; ainda não instalado)
- **Notes:** traço 1.5–2px, tamanhos 16–24px. Sem emoji como ícone de UI, sem misturar conjuntos.

## Movimento (decisão do projeto)

- Site de apresentação: **Padrão Magnus** — 0,4 a 0,9 s, só `transform` e `opacity`, com GSAP. Substitui os 100–300 ms da skill `motion` neste projeto (ver `docs/briefing.md`).
- Única exceção a "só transform e opacity": a assinatura da marca, o traço da navalha desenhado com GSAP DrawSVG (anima o traçado do SVG; só repinta, não mexe no layout).
- Uma assinatura (traço da navalha) + entradas curtas por bloco ao rolar. Nunca efeito em todo cartão.
- `prefers-reduced-motion: reduce` desliga tudo: sem entradas, traço já desenhado, poste 3D vira imagem, barra fixa sem transição.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
